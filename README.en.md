# 🎮 OBS Scoreboard App - White Bear Panel (For Yu-Gi-Oh! Master Duel Streaming)
![obs](https://github.com/user-attachments/assets/f8e27867-c428-4f24-aec7-9d49f5dbf537)

Make your Yu-Gi-Oh! Master Duel streams clearer and more engaging with OBS.  
This scoreboard app allows you to show first/second turn status and match results in real time, making it easy for your viewers to understand the flow of your matches.

## 🧩 Features

- Display the scoreboard in OBS using the **Window Capture** feature
- Use a separate **control panel window** to:
  - Switch between solid and chroma key background colors
  - Switch text color (white / black)
  - Input first / second turn
  - Input win / loss results
  - Input coin toss result (heads / tails)
- Automatically calculates and displays total matches and win rate
- English UI support
- Choose from 4 layout styles including the default
- Simple, stream-friendly interface

## 🖥️ How to Use

### 🎥 How to Display in OBS
![1](https://github.com/user-attachments/assets/11f5601a-5486-4fa8-9daa-0cfc6c515f19)
1. Launch the app
2. In OBS, add a **Window Capture** source and select "White Bear Panel"
3. Position and resize the scoreboard freely within OBS

### 🎛️ Using the Control Panel
![5f4bd1b6d34b459d](https://github.com/user-attachments/assets/e3d8a6a5-f8ee-43ac-be15-2891080418e2)

- The control panel opens in a separate window and allows the following actions:
  - Switch between Japanese and English UI (via menu bar)
  - Toggle between white/black backgrounds or enable chroma key background (via menu bar)
  - Switch between 4 available layouts (via menu bar)
  - Input coin toss result: `Heads` / `Tails`
  - Input turn order: `First` / `Second`
  - Input match result: `Win` / `Loss`  
    → Total matches and win rate update automatically
  - Reset button  
    → Clears all inputs (can be undone with the undo button)
  - Undo button  
    → Reverts the most recent input step-by-step. The initial state is used as the base.
